# Task 038: 마이페이지(개인화 허브)

> Phase 7 (개인화·콘텐츠 확장)
> 즐겨찾기·방문완료 등 로그인 사용자용 개인화 화면을 한곳으로 모으고, 헤더 진입점을 통합한다.

## 목표

즐겨찾기(Task 026)·방문완료(Task 037)가 각각 헤더에 직접 링크로 노출돼 개인화 화면이 늘수록 헤더가 비좁아진다. 이를 **마이페이지(`/mypage`) 단일 허브**로 모으고, 프로필 요약 + 개인화 화면 진입(개수 배지)을 제공한다. 앞으로 추가될 개인화 화면(알림 설정 등)의 확장 지점이다.

## 설계 결정 (이 Task에서 확정)

- **헤더 통합**: 즐겨찾기·방문완료 직접 링크 2개를 제거하고 **마이페이지 단일 진입점**으로 통합(`auth-button.tsx`). 로그인 시 마이페이지 + 로그아웃, 비로그인 시 로그인만 노출한다(예전엔 즐겨찾기 링크를 비로그인에도 노출해 proxy 로 로그인 유도했지만, 마이페이지는 개인 허브라 로그인 상태에서만 노출하는 편이 자연스럽다). 즐겨찾기·방문완료는 `/mypage` 안에서 진입한다.
- **보호 라우트**: `/mypage` 는 `proxy.ts` 공개 경로가 아니므로 자동으로 `/auth/login?next=/mypage` 게이트에 걸리고, 서버 컴포넌트가 `getClaims()` 로 이중 방어한다(즐겨찾기·방문완료와 동일 패턴). proxy 수정 불필요.
- **프로필 요약**: 이니셜 원형 아바타 + 표시이름 + 이메일. 표시이름은 `full_name → username → 이메일 local part → "등산객"` 폴백. 아바타는 외부 이미지(OAuth) 의존·CSP·`next/image` remotePatterns 설정을 피하려고 **이니셜 원형**으로 렌더한다(이메일 가입자는 아바타가 없으므로 견고).
- **개수 배지**: 즐겨찾기·방문완료 개수를 `select("*", { count: "exact", head: true })` 로 **행 전송 없이** 병렬 집계(RLS 로 본인 행만). 프로필 조회까지 한 번에 `Promise.all`.
- **진입 카드**: `MypageNavCard`(아이콘·라벨·설명·개수·href 만 받는 순수 표현 컴포넌트)로 즐겨찾기·방문완료·프로필 편집을 렌더. 개인화 화면이 늘어도 그대로 재사용한다. `count=null` 이면 배지를 숨긴다(프로필 편집).
- **프로필 편집**: 스타터의 기존 폼(`/protected/profile`)으로 링크한다(별도 편집 화면 신설은 범위 밖). 지금까지 UI 진입점이 없던 고아 페이지를 마이페이지가 흡수한다.

## 관련 파일

**신규**

- `app/(main)/mypage/page.tsx` — 허브(서버 컴포넌트, `<Suspense>` + 스켈레톤, `getClaims()` 이중 방어, 프로필·개수 병렬 조회).
- `components/mypage-nav-card.tsx` — 개인화 진입 카드(개수 배지·44px 터치 타깃).

**수정**

- `components/auth-button.tsx` — 헤더를 마이페이지 단일 진입점으로 통합(로그인/비로그인 분기).
- `components/site-header.tsx` — 인증 컨트롤 Suspense 폴백 폭을 새 컨트롤에 맞춤(CLS), 주석 갱신.

## 테스트 (Playwright MCP)

1. `sangil-e2e@example.com` 로그인(→ `next=/mypage` 복귀) → 헤더에 "마이페이지" 링크 + 로그아웃 노출.
2. 마이페이지: 프로필 요약(이니셜·이름·이메일) + 즐겨찾기 배지 **2** + 방문완료 배지 **1**(시드값과 일치) + 프로필 편집 + 로그아웃.
3. 로그아웃 → 헤더에 로그인만 노출(마이페이지 링크 사라짐).
4. 비로그인 `/mypage` 접근 → `/auth/login?next=%2Fmypage` 로 리다이렉트(보호 라우트).
5. 콘솔 에러 0, `typecheck`·`lint`·`build` 통과.

## 향후 확장 여지

- 마이페이지에 알림 설정·개인화 점수(체력/선호) 등 진입을 `MypageNavCard` 로 추가.
- 프로필 편집을 `/protected` 스타터 레이아웃에서 `(main)` 레이아웃으로 이관(일관된 헤더).
