## 2. 베이스라인 진단

### 2-1. 콘텐츠 성능은 이미 우수
배너 억제 상태(콘텐츠 격리) 측정 결과 상세 웜 LCP 568ms·콜드 LCP 1520ms로 **실제 콘텐츠는 목표를 이미 통과**. 이는 PPR 정적 셸 프리렌더 + 소스별 `<Suspense>` 독립 스트리밍(Task 019) 덕분. 번들도 슬림(총 `.next/static/chunks` 1.2MB, 최대 청크 244KB — 프레임워크/radix/cmdk).

### 2-2. 발견된 실제 결함 3건

1. **콜드 캐시 스트리밍 CLS 0.88** — 스트리밍 섹션(컨디션·날씨·탐방로)이 스태거드하게 도착할 때 스켈레톤이 실제 콘텐츠보다 크게 짧아(예: 날씨 스켈레톤은 요약 카드만 덮지만 실제는 요약+일출+시간별+3일예보 = 606px) 아래 섹션을 밀어냄. 웜 캐시는 모든 섹션이 거의 동시 도착해 한 프레임에 스왑되므로 CLS가 낮았음(콜드가 최악).
   - 실측 섹션 높이(설악산): 컨디션 767px, 날씨 606px, 지도 278px(고정).

2. **PWA 설치 배너가 LCP 요소로 잡힘** — 하단 고정 배너의 텍스트 블록(size 3933px²)이 컨디션 점수 span(3844px²)보다 근소하게 커, `beforeinstallprompt` 발화 시 늦게 등장하며 LCP를 최대 2412ms까지 끌어올림.

3. **헤더 하이드레이션 CLS** — `ThemeSwitcher`가 하이드레이션 전 `null`을 렌더 → 클라이언트에서 44px 버튼이 뒤늦게 나타나 헤더가 밀림. `AuthButton` Suspense 폴백 크기도 실제와 불일치.

> 참고: 초기 측정에서 관찰된 CLS 0.26~0.40은 서비스워커 캐시/타이밍 아티팩트로 **클린 런에서 재현되지 않음**(구조적 원인은 위 3건).

### 검증 (지연 로딩·번들·리렌더)
- **지도 지연 로딩 재확인**: 카카오맵 SDK는 `autoload=false` 스크립트를 마운트 시 1회 주입(모듈 스코프 캐시), 셸 렌더 후 비동기 부착 → **지도는 LCP 요소가 아님**(LCP=점수 span). 추가 조치 불요.
- **번들**: 상세 페이지가 쓰는 청크는 프레임워크/필수 프리미티브 중심으로, 위험한 축소 여지 없음. 무거운 클라이언트 컴포넌트 없음.
- **리렌더**: 탐방로 선택 강조는 컨텍스트 기반 국소 갱신으로 임계경로 밖. 개선 근거 없음.

## 4. 외부 API 캐시 히트율·TTL 실측 (🔶#8 확정)

콜드(캐시 미스, 첫 계산) vs 웜(캐시 히트) 응답시간 실측:

| 엔드포인트 | 콜드(미스) | 웜(히트) | 배속 | 비고 |
| --- | --- | --- | --- | --- |
| `/api/weather` | 1.16s | 43ms | ~27x | 기상청 단기예보 |
| `/api/air-quality` | 0.11–0.19s | 44ms | ~3x | 에어코리아(간헐적 13s 게이트웨이 지연 관측 — 아래) |
| `/api/uv` | 72ms | 24–35ms | ~2x | 생활기상지수 |
| `/api/trails` | 72ms | 44ms | — | DB 스냅샷(외부 API 없음, 항상 빠름) |
| `/api/condition` | 1.12s | 44ms | ~25x | 날씨·대기·자외선 병렬 조회 후 점수 계산 |

**TTL 판정**: 현행 `cacheLife` TTL(날씨 30m / 단기 3h / 대기 1h / 자외선 3h / 탐방로 6h / 산 마스터 1d)은 각 소스 발표 주기에 정렬(결정 003)돼 있고, 히트 지연이 40ms대로 우수함 → **재튜닝 불필요, 실측으로 적정성 확인**.

**에어코리아 게이트웨이 간헐 지연(1회 13.4s 관측)**: 시스템적 문제가 아닌 일시 현상(동일 조건 재측정 시 0.1s대). 방어책이 이미 존재 — 8s fetch 타임아웃(`lib/api/fetcher.ts`) + 대기질 소스 격리(`PartialResult`로 실패/지연 시 점수에서 변수 제외, `no_station`/`upstream_error` 폴백). 콜드 컨디션(히어로) 실측이 1.1s대인 것도 이 격리 덕분.
