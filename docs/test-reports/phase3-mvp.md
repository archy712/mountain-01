## 콘솔 오류

- 홈·상세·오프라인·not-found 앱 콘솔 **JS 에러 0건**. `browser_evaluate` fetch 테스트가 유발한 404/400 리소스 로그는 의도된 HTTP 응답(앱 크래시 아님).

- **정밀 4G 스로틀 LCP**·캐시 히트율 재조정 → Task 032.
