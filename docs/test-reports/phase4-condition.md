## 콘솔 오류

- 로그인·상세·즐겨찾기 플로우 앱 콘솔 **JS 에러 0건**. `browser_evaluate` 미인증 fetch가 유발한 401은 의도된 HTTP 응답(앱 크래시 아님).

## 발견 / 한계 (범위 밖)

- **`condition_scores` 영속 쓰기**: RLS상 쓰기는 서비스 롤 전용인데 `SUPABASE_SERVICE_ROLE_KEY` 미설정이라 현재 **저장은 graceful skip**(점수 계산·표시는 정상). 조회·버전·TTL 로직은 위 실쿼리로 검증. 키 설정 시 즉시 영속 활성화(코드 준비 완료). `/favorites` 점수 요약은 원천 데이터 `'use cache'`를 재사용해 산별 실시간 산출.
- **부분 폴백 라이브 배지**: 외부 대기질 API의 간헐적 실패에 의존(측정소·시각별). 렌더 시점 stale 폴백이 잡히면 배지가 안 보일 수 있어, **결정성은 단위 테스트로 보증**하고 라이브는 API 봉투(`excludedVariables`)로 실증.
- **보안 어드바이저**: `auth_leaked_password_protection`(WARN) — HaveIBeenPwned 유출 비밀번호 차단 미활성(프로젝트 Auth 설정 권고, 코드/ RLS 무관). `get_advisors(security)` RLS 경고 **0건**.
- **E2E 계정**: `sangil-e2e@example.com`·`sangil-e2e-2@example.com`(확인 완료) 검증용 상주. 테스트 favorites 데이터는 정리(0행).
