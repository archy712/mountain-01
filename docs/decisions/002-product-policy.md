## 🔶#2 — 검색 결과 라우트 구조

**결정: 산 선택 시 곧바로 `/mountains/[id]` 상세로 이동한다. 목록형 `/search?q=`는 채택하지 않는다.**

- 제품 핵심 가치("3초 안에 판단")에 부합 — 목록 페이지를 한 단계 생략하고 결론 화면으로 직행.
- 자동완성 드롭다운(홈 `/`)이 목록 역할을 대신하므로 별도 검색 결과 페이지 불필요.
- **동명 산 다건 매칭 처리:**
  - **자동완성 후보에서 지역명을 병기**하여 구분한다 (예: `북한산 (서울·경기)`, `금정산 (부산)`).
  - 각 후보는 고유 `mountains.id`를 가지므로 선택 즉시 해당 상세로 이동 → 라우트상 모호성 없음.
  - 링크/외부 진입 등으로 `id` 없이 이름만 있는 경우의 다건 처리는 MVP 범위 밖(자동완성 경유가 기본 진입로). 필요 시 후속에서 디스앰비규에이션 UI 추가.
- **확정 라우트 목록:** 아래 "확정 라우트 표" 참조.
- **영향 Task:** Task 005(라우트 골격), Task 009(자동완성 지역 병기), Task 018(검색 연동)

## 🔶#12 — 비로그인 정책

**결정: 1단계는 전면 비로그인 이용, 2단계 즐겨찾기부터 로그인 요구.**

- 검색~결과 확인(날씨·탐방로·컨디션 점수 조회)까지 **로그인 없이 전 흐름 완결**.
- 로그인은 **개인화 기능(즐겨찾기)에서만** 요구 → 진입 마찰 최소화.
- **`proxy.ts` 보호 경로 정책:**
  - **공개(비로그인 허용):** `/`, `/mountains/*`, `/mountains/[id]/map`, `/offline`
  - **보호(인증 요구):** `/favorites` — **1단계에서는 라우트 자체가 미노출/비활성, 2단계(Task 025)에서 보호 경로로 활성화**
  - `updateSession()`의 **쿠키 처리 로직은 변경 금지**(보호 경로 목록만 조정).
- 비로그인 사용자가 즐겨찾기(`FavoriteButton`) 클릭 시 로그인 유도 UX 노출.
- **영향 Task:** Task 005(초기 보호 경로), Task 025(`/favorites` 보호 활성화), Task 011(`FavoriteButton` 로그인 유도)

## 🔶#14 — `search_logs` 수집 여부

**결정: 익명 검색 로깅을 활성화한다 (insert-only, 개인정보 미수집).**

- 수집 필드: `query`(검색어), `mountain_id`(매칭 산, nullable), `created_at`. **사용자 식별정보(IP·user_id·쿠키 등) 저장 안 함.**
- 목적: 인기 산 목록 실데이터화, 검색량·검색→결과 확인 완료율 등 KPI 계측 근거.
- **RLS:** `insert` 공개 허용 / `select` 차단(분석은 서비스 롤·대시보드에서만). Task 007에서 SQL 확정.
- **개인정보 처리방침:** 개인 식별정보 미수집이므로 강한 동의 절차는 불필요하나, **"검색어를 익명 통계 목적으로 저장한다"는 취지의 1줄 고지**를 향후 처리방침/푸터에 포함(Task 034 운영 문서에서 반영).
- **영향 Task:** Task 007(`search_logs` DDL·RLS), Task 018(로깅 연동), Task 034(고지 문구)

## 🔶#7 — 산-격자좌표 사전 적재 방식

**결정: 초기 시드 배치 방식으로 확정. 시드 시 위경도→기상청 격자(nx, ny)를 일괄 변환하여 `mountains.grid_nx/grid_ny`에 사전 저장한다.**

- 조회 시점 변환 비용 0, 첫 조회 지연·경합 없음, 값이 결정론적이라 캐시/검증에 유리.
- 격자 변환 유틸(`lib/geo/kma-grid.ts`)은 **단위 검증** 후 시드 데이터 샘플과 교차 확인(리스크: 격자 변환 정확도).
- (참고) 최초 조회 시 계산 방식은 시드가 단순하나 첫 조회 지연·동시성 처리 부담이 있어 미채택.
- **영향 Task:** Task 014(시드 + `lib/geo/kma-grid.ts`), Task 006(`Mountain` 타입에 `gridNx/gridNy`)
