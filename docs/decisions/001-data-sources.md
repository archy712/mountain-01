## 🔶#4 — 탐방로 개방정보 소스

**결정: 국립공원공단 탐방로 개방정보 API를 1차 단일 소스로 사용하고, 미보유 산은 상태 "정보 없음"으로 명시 표기한다.**

- MVP는 국립공원 중심으로 빠르게 완결하고, 도립·군립·근교산 커버리지는 이후 점진 확장한다.
- 미보유 산의 "정보 없음"은 결함이 아니라 **정식 스펙**으로 승격한다 (오해 방지 문구 병기).
- **PoC 검증 항목 (키 발급 후):**
  - [ ] 실제 응답 필드(산명·탐방로명·개방상태·통제사유·통제기간) 및 갱신 주기 확인
  - [ ] 국립공원 외 산 커버리지 공백 측정 → 커버리지 검증표 작성
  - [ ] 외부 산/탐방로명 ↔ `mountains`/`trails` 매핑 난이도 확인 (명칭 정규화 필요 범위)
- **영향 Task:** Task 017(탐방로 연동), Task 010/019(정보 없음 폴백 UI)

## 🔶#15 — 등산로 GeoJSON

**결정: PoC로 데이터 확보 가능성을 먼저 판정하고, 확보 시 폴리라인 오버레이 / 미확보 시 마커+탐방로 목록 축소안으로 자동 전환한다.**

- Phase 5 스코프를 데이터 실현성에 맞춰 유연하게 결정한다.
- **PoC 검증 항목 (Phase 5 착수 전, 조기 판정):**
  - [ ] 국가공간정보포털/공공데이터 등산로 노선 데이터 유무 확인
  - [ ] 라이선스(상업/서비스 이용 가능 여부) 확인
  - [ ] 좌표 정밀도·포맷(GeoJSON 변환 난이도) 확인
- **미확보 시 축소안:** Task 029를 폴리라인 대신 "산 위치 마커 + 탐방로 목록"으로 대체, Phase 5 일정 재산정
- **영향 Task:** Task 028(카카오맵), Task 029(오버레이/축소 폴백)

## 🔶#3 — 기상청 예보 API

**결정: 초단기실황/초단기예보 + 단기예보 혼용.**

- **당일(D-0) 현재값:** 초단기실황 / 향후 수시간: 초단기예보
- **익일 이후:** 단기예보(3시간 단위)
- 가장 정확하며 "지금 날씨"와 "내일 갈 만한가"를 모두 커버한다. `base_date`/`base_time` 발표 시각 규칙 구현 필요.
- **영향 Task:** Task 016(기상청 연동 — base_time 산출 로직 포함)

## 🔶#5 — 미세먼지 측정소 매핑

**결정: 산 위경도 기준 최근접 측정소 자동 매핑 + 거리 임계값.**

- 거리 임계값(초안 20km, PoC로 조정) 초과 시 "인근 측정소 없음"으로 처리하고 컨디션 점수에서 해당 변수 제외.
- 매핑 결과는 캐싱하여 반복 계산 방지.
- **영향 Task:** Task 021(미세먼지 연동), `lib/geo/nearest-station.ts`
