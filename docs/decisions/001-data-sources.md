## 🔶#6 — 자외선 API

**결정: 기상청 생활기상지수 조회서비스 V5의 자외선지수 조회(`getUVIdxV5`)로 확정.** (※ 엔드포인트 버전 **V5** — 초안 3.0 → 4.0 → **V5로 최종 정정**)

- **확정 엔드포인트:** `GET https://apis.data.go.kr/1360000/LivingWthrIdxServiceV5/getUVIdxV5`
  - 파라미터: `serviceKey`(Encoding 그대로), `areaNo`(행정구역코드 10자리), `time`(YYYYMMDDHH, **06·18시 발표**), `dataType=JSON`, `numOfRows`, `pageNo`
  - `areaNo`는 서비스 상세 페이지 첨부 "지역코드" 파일에서 확정
- 공신력 있는 무료 소스이며, 지역코드(행정구역) 매핑 방식으로 조회.
- **현재 상태(2026-08-08 재테스트):** ✅ **라이브 정상**(HTTP 200, `resultCode=00 NORMAL_SERVICE`, totalCount=1). `KMA_LIVING_INDEX_KEY`(3키 동일 값)로 정상 조회.
  - **직전 코드30 원인 규명:** 이전 실패는 키/게이트웨이 문제가 아니라 **엔드포인트 버전 오류**(`LivingWthrIdxServiceV4/getUVIdxV4`)였음. V4 경로는 이 계정 키에 미등록이라 코드30 반환. **V5 경로로 교체하니 즉시 정상.**
  - 응답 스키마: `items.item[0]`에 `code`(지역), `areaNo`, `date`(YYYYMMDDHH 발표시각), **`h0`~`h75`(발표시각 기준 3시간 간격 UV 지수 예보값)**. 값 없는 시간대는 빈 문자열. → Task 022에서 `h0`(현재 시각 인근)~단기 구간 파싱.
- 에어코리아·기상청 단기예보도 라이브 **정상 확인됨** (2026-08-08 재테스트 통과).
- **영향 Task:** Task 022(자외선 연동 — 지역코드 매핑)

## 100대명산 목록·좌표 (Task 036)

**결정: 산림청 선정 100대명산(2002)을 산 마스터 콘텐츠로 편입한다. 목록/고도/지역은 공개 사실 데이터, 좌표는 기존 시드와 동일한 "대표 정상 근사값" 기준을 적용한다.**

- **목록·고도·지역 출처:** 위키백과 "대한민국 100대 명산 목록"(산림청 2002년 선정 공표 목록). 100대명산 "선정 목록" 자체는 저작권 대상이 아닌 공개 사실 정보이며, 산 이름·소재지(도)·해발고도는 공표 자료 기준으로 표기한다.
- **좌표(lat/lng):** 대표 정상 근사값을 사용한다(기존 `gen-mountains.mjs`와 동일 기준). 컨디션·날씨는 기상청 **5km 격자**로 조회되므로 정상 근사 좌표로 충분하다.
- **정밀 좌표 정식 소스(향후):** 한국등산·트레킹지원센터 **100대명산 목록정보 서비스**(공공데이터포털 `15125127`, 위도·경도·해발고도·주소 제공). 현재 이 계정에 미구독(활용신청 필요)이라 좌표 정밀화는 후속 과제로 남긴다.
- **동명 산 처리:** 100대명산에는 동명 산이 존재(백운산 3곳·지리산 2곳·남산은 경주). 검색은 지역명 병기로 구분(결정 002 #2)하며, 기존 서울 남산/북악산/인왕산/수락산/청계산은 100대명산이 아니므로 `is_top100=false`로 유지한다.
- **영향 Task:** Task 036(100대명산 목록 화면)
