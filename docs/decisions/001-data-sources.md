## 🔶#4 — 탐방로 개방정보 소스

**결정: 국립공원공단 탐방로 데이터를 1차 소스로 사용하고, 미보유 산은 상태 "정보 없음"으로 명시 표기한다.**

- **확보 데이터 (`mountain.csv`, 국립공원공단 — 91만 점 / 625 코스 / 22개 사무소, CP949 인코딩):** `탐방로 통제여부`(0/1) + `통제구간 설명`(예: `산불방지통제구간(3월 1일~4월 30일)`) 포함.
- 💡 **계절 통제는 기간이 데이터에 명시돼 있어 오늘 날짜와 비교하면 API 없이도 "오늘 통제 여부"를 결정적으로 계산 가능** → MVP `#4` 베이스라인으로 채택.
- **한계:** 정적 2023 스냅샷 → 사고·낙석·기상 등 **실시간 돌발 통제는 미반영**. 필요 시 라이브 국립공원공단 개방정보로 보완, 아니면 폴백 유지.
- MVP는 국립공원 중심으로 완결, 도립·군립·근교산은 "정보 없음" 폴백(정식 스펙)으로 처리 후 점진 확장.
- **후속 검증 항목:**
  - [ ] 계절 통제 기간 파싱 및 "오늘 통제 여부" 계산 로직
  - [ ] 실시간 돌발 통제 보완 필요성 판단(라이브 API 유무 재확인)
  - [ ] 코스 식별키 정의(관리번호/코스ID/사무소코드) 및 `mountains` 매핑
- **영향 Task:** Task 017(탐방로 연동), Task 010/019(정보 없음 폴백 UI)

## 🔶#15 — 등산로 GeoJSON

**결정: 국립공원공단 CSV(`mountain.csv`)를 소스로 폴리라인 오버레이를 정식 구현한다. (PoC 통과 — 축소안 불요)**

- **PoC 결과:** CP949 파싱 → WGS84 위경도 → GeoJSON LineString 변환 성공. **좌표가 이미 위경도라 카카오맵 재투영 불필요.** RDP 단순화로 용량 대폭 축소 확인(수통골 2코스 GeoJSON 38%로 축소).
- 전 국립공원 625개 코스 커버. 난이도·거리·소요시간 메타 동시 확보.
- **적재 전략:** 173MB 원본은 로컬 가공용(gitignore 처리). 코스별 그룹핑 → 단순화 → `trails.path_geojson`에 필요분만 적재(수 MB 예상, 무료 티어 500MB에 무리 없음).
- **후속 검증 항목:**
  - [ ] 코스 조립 키 정의 — 일부 `국립공원관리번호`가 다수 코스 뭉침(16만 점)/과분할(34 점) → 관리번호+코스ID+사무소코드 조합 및 점 순서 정렬 규칙 확정
  - [ ] 라이선스(표준데이터 이용범위) 확인
  - [ ] 더 넓은 커버리지 필요 시 산림청 전국등산로표준데이터(15029184) 추가 검토
- **영향 Task:** Task 028(카카오맵), Task 029(GeoJSON 적재·오버레이)

## 🔶#3 — 기상청 예보 API

**결정: 초단기실황/초단기예보 + 단기예보 혼용.**

- **당일(D-0) 현재값:** 초단기실황 / 향후 수시간: 초단기예보

## 🔶#6 — 자외선 API

**결정: 기상청 생활기상지수 조회서비스(4.0)의 자외선지수 조회로 확정.** (※ 서비스 버전 **4.0** — 초안의 3.0에서 정정)

- **확정 엔드포인트:** `GET https://apis.data.go.kr/1360000/LivingWthrIdxServiceV4/getUVIdxV4`
  - 파라미터: `serviceKey`(Encoding 그대로), `areaNo`(행정구역코드 10자리), `time`(YYYYMMDDHH, **06·18시 발표**), `dataType=JSON`, `numOfRows`, `pageNo`
  - `areaNo`는 서비스 상세 페이지 첨부 "지역코드" 파일에서 확정
- 공신력 있는 무료 소스이며, 지역코드(행정구역) 매핑 방식으로 조회.
- **현재 상태:** 활용신청 **승인 완료(2026-08-08)**. 라이브 테스트 시 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR(코드 30)` → 승인 직후 **게이트웨이 활성화 지연(~1시간)**으로 판단(키·엔드포인트 정상). 활성화 후 동일 키(`KMA_LIVING_INDEX_KEY`)로 작동 예정.
- 에어코리아·기상청 단기예보는 라이브 테스트로 정상 확인됨.
- **영향 Task:** Task 022(자외선 연동 — 지역코드 매핑)
